# pet-admittracker

## Тренажёрный зал

Учебный веб-проект для записи клиентов на тренировки и просмотра расписания. Используются только HTML, CSS и JavaScript без фреймворков и сборщиков.

## Стек
- HTML
- CSS
- JavaScript

## Основные функции
- форма записи на тренировку (имя, дата и время, тип тренировки)
- список расписания тренировок

## Структура проекта
- `index.html` — главная страница
- `css/style.css` — стили
- `js/main.js` — логика формы записи
- `docs/passport.md` — паспорт проекта

## Как запустить
Откройте файл `index.html` в браузере или запустите его через расширение Live Server (кнопка Go Live в VS Code).
