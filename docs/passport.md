# Паспорт проекта

**Название:** Тренажёрный зал
**Назначение:** веб-приложение для записи клиентов на тренировки и просмотра расписания.
**Стек:** HTML, CSS, JavaScript
**Основные функции:**
- форма записи на тренировку
- список расписания тренировок
**Целевая аудитория:** посетители тренажёрного зала
**Статус:** каркас MVP
